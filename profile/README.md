## About

Passion Factory is an AI solutions company. We build chatbots, image analysis, and personalized
recommendation systems, and we deliver user-centered digital products on top of proven AI
technology and data expertise.

This organization is where we publish the tooling and libraries we build in the course of that
work. Repositories are on the way — watch this space, or reach out if you want to hear what is
coming.

## Contributing

Issues and pull requests are welcome on every public repository here. Each repository carries its
own `CONTRIBUTING.md` and states its license; when a repository has no contribution guide yet,
open an issue first so we can agree on the direction before you spend time on a patch.

## Security

Please do not report security issues through public issues. Email
[oss@passionfactory.ai](mailto:oss@passionfactory.ai) instead, or use the private vulnerability
reporting form on the affected repository.
